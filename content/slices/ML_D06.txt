determine geometric distances.

Each split is perpendicular to one feature axis and parallel to the remaining axes. Repeated splits therefore partition the

This structure is well suited to threshold effects, such as a return regime that changes when RSI exceeds a particular 
value. However, a diagonal boundary such as 
𝑋₁+𝑋₂ >𝐶 
does not align with either feature axis. A standard tree must approximate it using a staircase of horizontal and vertical 
partitions, potentially requiring many splits. The precise number depends on the data distribution and the desired 
approximation accuracy.  
C. True – CART uses greedy, top-down recursive binary splitting. For regression with squared-error loss, it searches 
candidate pairs (𝑗,𝑠)and selects the pair that minimizes the total within-node squared error: 
Σ_(𝑥ᵢ∈𝑅₁(𝑗,𝑠)) (𝑦ᵢ −ȳ_(𝑅₁))² + Σ_(𝑥ᵢ∈𝑅₂(𝑗,𝑠)) (𝑦ᵢ −ȳ_(𝑅₂))².

The search is greedy because CART selects the best split for the current node without jointly optimizing the complete

use sorting and other computational optimizations rather than recomputing every split naively.

its predictions can change substantially. 
This high-variance behavior is one reason trees are commonly pruned or constrained using parameters such as maximum 
depth, minimum leaf size, and minimum impurity reduction. Ensemble methods such as bagging and random forests 
also reduce variance by averaging predictions across multiple trees. 
The sensitivity is possible rather than inevitable: not every small data change will alter a root-level split, but individual 
deep trees are generally less stable than lower-variance models.

[ML-D6G2Q1] 
A classiﬁcation tree is considering two root splits for predicting whether a stock will outperform. Split A creates child 
nodes that are each strongly dominated by one class. Split B creates two child nodes with nearly equal mixtures of 
outperformers and underperformers. The split criterion rewards reductions in class impurity. 
 
A. Split A is likely to produce a larger impurity reduction than Split B. 
B. A pure child node contains observations from only one target class. 
C. The feature with the largest numerical scale must be selected for the split. 
D. The target labels are used when evaluating candidate splits during supervised tree training. 
E. An impurity reduction at the root guarantees minimum possible test error. 
 
Answer Key: 
 
A. True – Separating the classes produces purer children and usually a larger impurity decrease. 
B. True – A node is pure when all of its training observations have the same class label. 
C. False – Candidate splits are compared by their criterion values, not by raw feature scale. 
D. True – Supervised splitting measures how well feature thresholds separate known targets. 
E. False – A locally useful training split does not guarantee globally optimal structure or test performance.

You are a Machine Learning Researcher at a quantitative hedge fund developing a decision tree model to classify stocks 
as potential outperformers or underperformers. The Portfolio Manager notices that the tree keeps selecting splits that 
reduce prediction errors in the current dataset and asks whether these decisions represent a globally optimized 
investment strategy. You are asked to explain how decision trees choose splits and what limitations arise from their 
splitting approach. 
 
A. Decision trees typically choose splits using a greedy approach that selects the best available split at each step. 
B. A split that improves the current node’s prediction quality is always guaranteed to produce the globally optimal ﬁnal 
decision tree. 
C. Decision tree splitting criteria aim to create child nodes that are more homogeneous or have lower prediction error 
than the original node. 
D. Decision trees evaluate every possible combination of future splits before selecting the ﬁrst split at the root node. 
E. The quality of a split can be evaluated by how much it reduces impurity or prediction error in the resulting groups. 
 
Answer Key: 
 
A. True – Decision trees use a greedy algorithm that selects the best split at the current stage without considering all 
possible future split combinations.  
B. False – A locally optimal split does not guarantee a globally optimal tree because future splits and interactions among 
decisions are not fully considered during the greedy construction process.  
C. True – Splitting criteria are designed to create groups where observations are more similar, reducing measures such 
as classiﬁcation impurity or regression error within each resulting node.  
D. False – Decision trees do not search all possible combinations of splits because that would be computationally 
expensive. Instead, they build trees recursively using greedy split selection.  
E. True – A good split is one that improves the quality of the resulting nodes by reducing impurity for classiﬁcation or 
reducing error for regression.
