[ML-D3G1Q1] 
An equity team predicts next-month returns from company ﬁnancial statements. The PM proposes using raw revenue 
alone, while an analyst argues that revenue growth and proﬁt margin may better compare ﬁrms of different sizes. The 
team must improve the signal without incorporating information unavailable on the prediction date. 
 
A. Revenue growth can capture a change over time that a single revenue level does not express directly. 
B. Dividing proﬁt by revenue may create a scale-adjusted feature that is more comparable across ﬁrms. 
C. Every derived feature necessarily adds new information that was absent from the raw inputs. 
D. The dates on which ﬁnancial statements became publicly available matter when constructing these features. 
E. Feature engineering is useful only for linear models and cannot help distance-based learners. 
 
Answer Key: 
 
A. True – Growth represents a temporal relationship rather than only the current level. 
B. True – A margin normalizes proﬁt by ﬁrm activity and can support cross-ﬁrm comparisons. 
C. False – A transformation may merely restate existing information and can be redundant. 
D. True – Using ﬁgures before their publication would make the historical feature unavailable in practice.

E. False – Appropriate transformations can also improve distance measures and neighborhood structure.

[ML-D3G1Q4] 
A multi-factor equity model utilizes a rolling 12-month Ordinary Least Squares (OLS) Linear Regression to estimate the 
beta (β) of individual technology stocks relative to the Nasdaq 100 index. The model uses these rolling beta estimates as 
a primary feature to predict cross-sectional next-week returns. During a sudden, high-volatility market pivot, the model's 
predictive performance degrades rapidly, and an audit reveals that the estimated coefficients were highly unstable. 
For this question, mark each statement True if it is incorrect and False if it is accurate. 
 
A. The instability of the beta coefficients is a classic symptom of Non-Stationarity in ﬁnancial time series, meaning the 
underlying statistical relationship between the individual stocks and the index is changing over time. 
B. Using a ﬁxed, rolling 12-month window completely eliminates the risk of non-stationarity because it forces the OLS 
regression to constantly discard obsolete historical data, ensuring a stable parameter space. 
C. This pipeline suffers from a structural ﬂaw because standard OLS regression assumes that the underlying data-
generating process is Stationary (constant mean and variance), an assumption that routinely breaks down during market 
regime shifts. 
D. The rapid degradation in model performance is due to a Structural Break, where the historical covariance matrix 
calculated over the stable 12-month period fails to capture the sudden, step-function change in market dynamics. 
E. To adapt this linear framework to a non-stationary environment without changing the feature deﬁnitions, the weights 
of the regression should be modiﬁed using an exponential decay factor that prioritizes recent observations over distant 
ones. 
 
Answer Key (True = incorrect; False = accurate): 
 
A. False – Financial regimes are dynamic. A beta calculated during a low-volatility bull market will completely 
misrepresent an asset's systemic risk when a market shock occurs.  
B. True – Rolling windows mitigate, but do not eliminate, non-stationarity. If a structural break occurs within the current 
window, the OLS parameters will be a polluted average of two completely different regimes.

C. False – OLS regression assumes that the residuals are homoscedastic and independent. When regimes shift, the 
parameters shift, violating the core assumption that the underlying distribution is invariant.  
D. False – A structural break fundamentally changes the parameters of the system. The historical 12-month data acts as 
an anchor, preventing the model from recognizing the new structural reality until the old data drops out of the window.  
E. False – Switching to an exponentially weighted moving regression or a state-space model (like a Kalman Filter) allows 
the parameter estimation to adapt dynamically to drifting distributions.  
 
[ML-D3G1Q5] 
An algorithmic momentum portfolio uses a machine learning classiﬁer to predict whether a stock index will experience a 
positive or negative return over the next 20 trading days. The raw feature input is the 50-day rolling variance of daily 
returns. The system evaluates this feature using an Augmented Dickey-Fuller (ADF) Test, which rejects the null hypothesis 
of a unit root (p<0.01). Based on this result, the pipeline passes the raw rolling variance series directly into a deep neural 
network without further transformation. During a prolonged market regime shift, the model's accuracy collapses, and an 
internal audit reveals that the rolling variance feature exhibited severe structural drift. 
Which of the following statements correctly diagnoses why the ADF test failed to prevent this distribution shift, and 
identiﬁes the correct mathematical remedy? 
 
A. The ADF test is structurally incapable of detecting non-stationarity driven by stochastic trends, meaning it can only 
validate stationarity for series with ﬁxed, deterministic linear trends. 
B. The rolling variance series failed to maintain stationarity because the ADF test requires a minimum window length of 
252 trading days to properly evaluate the presence of a unit root in second-moment statistical features. 
C. The rejection of the null hypothesis by the ADF test mathematically guarantees that all statistical moments—including 
the mean, variance, and unconditional autocovariance—are perfectly invariant over the entire backtest horizon. 
D. The collapse occurred because the ADF test assumes the underlying data follows a Gaussian distribution; when 
applied to bounded, non-negative features like rolling variance, the test produces a high rate of false negatives. 
E. The ADF test only checks for a speciﬁc type of non-stationarity (a unit root/stochastic trend in the mean); it can easily 
register a series as "stationary" even if the feature suffers from structural breaks or structural drift in its variance over 
time. 
 
Answer Key: 
 
A. False – The ADF test is speciﬁcally designed to detect stochastic trends (unit roots). It handles deterministic trends by 
including a time-trend component (βt) in its test regression.  
B. False – There is no arbitrary 252-day structural minimum required by the ADF test framework; its validity depends on 
sample size, lag structure, and the underlying data-generating process, not a speciﬁc calendar constraint.  
C. False – A rejected ADF test is not a blanket guarantee of absolute stationarity. It simply means the series does not 
exhibit a random walk; it can still suffer from structural breaks, heteroscedasticity, or seasonal non-stationarity.  
 
 72 Rev:081020261230 
D. False – While the standard Dickey-Fuller distribution assumes independent and identically distributed errors, the test 
does not mechanically fail or invert its error rates solely because a feature is bounded or non-negative.  
E. True – This highlights a critical limitation of the test in feature engineering. A series can be mean-reverting (no unit root) 
but still have its underlying distribution warp due to regime shifts or variance changes, which the ADF test does not 
account for.

G2: Scaling and Normalization Effects 
[ML-D3G2Q1] 
A wealth manager uses KNN to identify historical days similar to the current market. One input is daily return measured 
near 0.01, while another is trading volume measured in millions of shares. The PM asks why the neighbors appear to be 
determined almost entirely by volume. 
 
A. Without scaling, a large-magnitude feature can dominate a Euclidean distance calculation. 
B. Standardizing the features can cause both return and volume to contribute on more comparable numerical scales. 
C. Feature scaling guarantees that both features contain equal predictive information. 
D. The scaling parameters should be estimated from the training data rather than the held-out test data. 
E. KNN predictions are always unchanged by rescaling one input feature. 
 
Answer Key: 
 
A. True – Numerical magnitude directly affects distance unless the inputs are adjusted. 
B. True – Standardization reduces dominance caused solely by differing units or ranges. 
C. False – Scaling changes numerical inﬂuence, not the underlying information content. 
D. True – Fitting preprocessing on test data weakens train/test separation. 
E. False – Rescaling can change which observations are nearest.

B. The standardization pipeline suffered from Outlier Truncation Bias, which is an inherent limitation of linear

D. True – This is a classic pitfall when standardizing non-stationary ﬁnancial data. When an extreme regime shift occurs, 
the rolling standard deviation (σ) increases rapidly. This expanding denominator deﬂates the resulting Z-score, masking
