G1: Motivation for Ensembles 
[ML-D7G1Q1] 
A portfolio manager has ﬁve independently trained regression trees that estimate next-day returns. Each tree is 
moderately accurate but its predictions vary substantially when the training sample changes; the manager asks whether 
averaging their forecasts could make position sizing more stable without changing the trading universe. 
 
A. Averaging can reduce prediction variance when the trees do not make perfectly correlated errors. 
B. The ensemble is guaranteed to outperform its best member on every future observation. 
C. If each tree has the same systematic directional bias, averaging alone may preserve much of that bias. 
D. Aggregation can be useful even when no individual tree is consistently the best model. 
E. Averaging ﬁve predictions is equivalent to selecting the prediction from the deepest tree. 
 
Answer Key: 
 
A. True – Imperfectly correlated errors can partially cancel in an average. 
B. False – An ensemble may improve expected performance, but it has no observation-by-observation guarantee. 
C. True – Shared systematic error does not disappear merely because predictions are averaged. 
D. True – Combining unstable learners can produce a more reliable aggregate than repeatedly choosing one learner. 
E. False – Averaging uses all ﬁve outputs rather than selecting one tree by depth.

individually—and averaging their predictions together to smooth out random noise. 
B. Each individual tree in a bagged ensemble is built using a bootstrap sample, which is created by randomly drawing 
observations from the training dataset with replacement. 
C. Because each bootstrap sample leaves out roughly one-third of the original training data, these "out-of-bag"

D. Bagging works best when base decision trees are pruned down to very shallow depths (max_depth = 1 or 2) because

Averaging predictions across hundreds of deep trees cancels out sample-speciﬁc noise, signiﬁcantly lowering overall

the original N observations.

cross-validation check.  
D. True – Bagging relies on using deep, unconstrained trees with high ﬂexibility (low bias). If you average shallow trees 
(high bias), averaging reduces variance slightly but leaves the high systematic error unchanged.  
E. False – Because all bootstrap samples are drawn from the exact same pool of historical data, a strongly predictive 
feature will likely be selected as the root split in almost every tree. This keeps the trees correlated with one another, which 
limits how much bagging alone can reduce variance.

C. Averaging 50 underestimates must produce an unbiased cost estimate. 
D. Regime shift can expose a weakness shared by every learner because their training experience was similar. 
E. Stress testing by regime can reveal vulnerabilities that average validation metrics may hide. 
 
Answer Key: 
 
A. False – Effective diversity concerns behavior and errors, not just member count. 
B. True – Common errors survive aggregation. 
C. False – An average of systematically low estimates can remain systematically low. 
D. True – Shared data and features can lead to the same extrapolation failure.

E. True – Segment-level evaluation can uncover concentrated failures in adverse conditions.
